A few good questions

Curious? You’re in good company.

My child has never coded. Where should we start?

Ages 6–9 usually begin with Scratch or Code.org. Ages 10 and up can jump into Thunkable or Python. Not sure? Book a free demo and we’ll recommend one.

Do we need to install anything?

No. Scratch, Code.org and Thunkable run in the browser. Python and web dev use free tools we’ll help you set up in the first class.

Are the classes live?

Yes. Every class is live online with a teacher, in 1:1 sessions so your child gets full attention.

How do we book?

Choose a course above and tap “Enquire”. We’ll share current schedules, fees and the booking link.
